# 审核一条龙：把用户提交的菜单收进数据库

用户在小程序/网页点「📷 拍照上传菜单」交上来的东西，最后落地到 `data/shops.json` 和
`data/db.js`，要跑 6 个脚本。这个文件夹把 6 个脚本串成一条线，中间只剩一步必须人工。

## 你要做的事（就三步）

**第 1 步 · 把待审核的包下载下来**

浏览器打开（`你的密钥` 就是后端环境变量 `SUBMIT_ADMIN_KEY` 的值）：

    https://fanfan-web-qpznnriewb.cn-hangzhou.fcapp.run/api/submit/pending?key=你的密钥

浏览器会存成一个 `fanfan-pending-2026-10-08.json` 这样的文件。

**第 2 步 · 双击 `一键审核.bat`，按提示回答**

它会问你：提交包在哪、店名、校内档口还是校外店、新菜的 id 前缀、饭饭账号密码
（校内档口还多问食堂/档口名/菜系/人均）。

> 店名尽量跟高德上写的一样 —— 菜单是"挂到高德搜到的店"上的，名字对不上就挂不上去。
> id 前缀 2~6 个小写字母，别和现有的重（已用过的：`cp cq d cn sx nd mg lz sn hb xjx cx pg zhxa yxc akxc`）。
> 账号没有就随便起一个，脚本会自动注册；它只是用来借后端 `/api/llm` 做识别，本机不放 Key。

**第 3 步 · 它停下来的时候，改那一份 json**

它会打印出识别结果 json 的完整路径，让你打开改三件事：

1. **价格**：看有没有"还是没配到价格"的菜，对着原照片把 `price` 填上（真免费就填 `0`）
2. **菜名**：OCR 认花的字（"水皎""干豆镉"这种）改成正确的
3. **看一遍有没有漏菜**

改完存盘，回到那个黑窗口按回车。剩下的（入库 → 生成前端数据 → 补新菜）它自己跑完。

## 跑完之后

1. 双击 `index.html`，在「发现美食」里找到这家店，把菜单逐条对一遍
2. 让 Codex 推上线（或者自己跑推送脚本）
3. 把这条从待审核池里划掉：

       curl -X POST https://fanfan-web-qpznnriewb.cn-hangzhou.fcapp.run/api/submit/review ^
         -H "Content-Type: application/json" ^
         -d "{\"key\":\"你的密钥\",\"ids\":[\"那条的 id\"],\"status\":\"accepted\"}"

## 这条链背后是 6 个脚本（出问题时按这个顺序查）

| 步骤 | 脚本 | 干什么 |
| --- | --- | --- |
| ① | `开发脚本/解析提交包.mjs` | 把包里的 base64 图片落盘，生成人工核对单 |
| ② | `开发脚本/import-menu.mjs` | 图片 → Windows 自带 OCR（带坐标）→ 大模型整理成结构化菜单 |
| ③ | `开发脚本/对照原文补价格.mjs` | 对着 OCR 原文把漏掉的价格补回来（不调大模型，配不到就留空） |
| ④ | —— | **人工**：改价格、改名、查漏 |
| ⑤ | `开发脚本/ingest-menu.mjs` | 菜单入库：`data/db.js` 缺的菜插进去，写 `商家数据库/解析结果/<店名>.json` |
| ⑥ | `开发脚本/build-data.mjs` | 生成 `data/shops.json` + 页面里的 `SHOP_DB_BUILTIN` 快照 |
| ⑦ | `gen-kb-records.mjs` + `insert-dishes.mjs` | 只在⑥报"有新菜"时才跑：给新菜生成规范记录再插库 |

## 几个踩过的坑（省得再踩）

- **别在 cmd/GBK 的窗口里直接跑 OCR**：`ocr-image.ps1` 要强制 UTF-8 输出，否则"元"和菜名全变成
  替换字符，价格全部配不出来。`一键审核.bat` 开头已经 `chcp 65001`。
- **一次提交有多张照片**：`import-menu.mjs` 传 `--shop` 会把它们合并成一份，别一张一张跑。
- **价格绝不猜**：原文里没有就不填，宁可留着 NULL 等人工。
- **校外店不要写 `place`**：只写 `city + cuisine + avg`；校内档口才写
  `place:'campus' + campus + canteen + stall + cuisine + avg`。写错了这家店在校内/校外模式里会串。
- 工作目录固定是 `商家数据库/待审核-<日期>/`，里面 `_解析/` 放识别结果和 OCR 原文，
  店名那个文件夹放照片和 `提交信息.json`。
