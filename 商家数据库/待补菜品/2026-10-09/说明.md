## 怎么用（你只要做一件事：填价格）

打开 `待定价-高频.csv`（Excel 直接开，是 UTF-8 带 BOM 的），在 **`价格(你填)`** 那一列填价格，
顺手做两件事：

1. 不想要的候选**直接删行**（比如"烤串（烧烤）"这种太笼统的）
2. 想微调的，`建议名` 那一列可以直接改（比如"牛肉（火锅）"改成"肥牛（火锅）"）

填完把文件发回给我就行。

## 关于命名：为什么火锅的要写「毛肚（火锅）」

程序里 `normDishName()` 会**抹掉括号**做归一化，所以「毛肚（火锅）」在匹配时等同「毛肚」——
好处是菜单上写"毛肚"也能对上；风险是**大库里如果已经有一条叫「毛肚」的菜，两条就会撞名**。
所以规则是：**只有大库里没有同名的时候，才用「XX（火锅）」这种后缀**（这份表里已经这么筛过一遍了，
`库里可能已有` 那一列就是提示，比如"毛肚（火锅）"旁边写着"重庆火锅毛肚"——那说明已经有一道了，
你可能不想要第二条）。

## 以后要再补的话，流程是这样

1. 按 `建议名 / 建议菜系 / 建议角色` 生成 `data/db.js` 记录：`id`（用新前缀，不与现有冲突）、
   `cat / cui / price / spicy / tags / alg / desc / hot`
2. `build-data.mjs` 重建 `data/shops.json` 和页面快照
3. 跑回归（`check-syntax / test-shop-db / check-campus / check-menu-links / smoke-ui` 等）
4. 推上线，并把这次补了哪些菜写成清单给你留档

价格一律以你填的为准，程序不会自己猜价（这是我们一直守的规矩：价格必须来自原文/人工确认）。
